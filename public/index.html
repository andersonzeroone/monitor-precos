Números de WhatsApp

Verificando conexão…

No celular: WhatsApp → Configurações → Aparelhos conectados → Conectar aparelho e aponte a câmera para o QR code.

Os alertas saem do número conectado. Mensagens para o próprio número conectado chegam no chat “Você”, normalmente sem notificação. Para receber com som, conecte um segundo número (ex.: um chip extra) ou envie para outras pessoas.
